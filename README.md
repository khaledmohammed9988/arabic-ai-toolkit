# Arabic AI Toolkit

Small, dependency-free utilities for evaluating Arabic text generated by AI systems.

The project focuses on two recurring problems in Arabic model evaluation:

- normalizing orthographic variation without hiding meaningful errors;
- producing reproducible, inspectable scores from JSONL evaluation cases.

## Features

- Arabic diacritic and tatweel removal
- configurable Alef, Yeh, and Teh Marbuta normalization
- exact-match and token-level precision, recall, and F1
- command-line evaluation of JSONL files
- machine-readable output for CI and benchmark pipelines
- standard-library test suite

## Quick start

```bash
python -m arabic_ai_toolkit.cli examples/sample_cases.jsonl
```

Example input:

```json
{"id":"case-1","reference":"الذكاء الاصطناعي","prediction":"الذَّكاء الاصطناعي"}
{"id":"case-2","reference":"تحليل البيانات","prediction":"تحليل بيانات"}
```

Example output:

```json
{
  "cases": 2,
  "exact_match": 0.5,
  "token_precision": 0.75,
  "token_recall": 0.75,
  "token_f1": 0.75
}
```

## Install for development

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
```

## Design choices

Normalization is intentionally conservative. Punctuation and digits remain visible, while common spelling variants can be normalized explicitly. The evaluator reports aggregate scores and can emit per-case diagnostics so low scores remain traceable to individual examples.
